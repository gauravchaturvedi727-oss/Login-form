# 🔐 Login Form

A modern and responsive **Login Form** built using **HTML, CSS, and JavaScript**. The project features a beautiful Glassmorphism UI, responsive design, strong form validation, animations, and an interactive user experience.

## ✔ Form Validation

The login form validates:

- Email cannot be empty
- Valid email format
- Password cannot be empty
- Minimum 8 characters
- At least one uppercase letter
- At least one number
- At least one special character
